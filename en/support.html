Frequently asked questions

Which devices does CVI PDF run on?

iPads with iPadOS 18 or later and Macs with macOS 15 or later.

Where do I find the edited PDF?

When saving, you choose the location in Files. The file has the original name with _CVI added.

A scanned sheet is not read correctly.

Good lighting and a straight scan help most. Text recognition can misread single letters – the report shows which pages should be checked.

Why is a page reflowed even with “Keep layout”?

With a larger font or more spacing, the text often no longer fits its original place. The app then reflows that page instead of cutting or shrinking text.

A table looks different from the original.

Tables are rebuilt with a clear grid. If a table is too wide for the chosen font size, the cells of each row are stacked. Cells spanning several lines are not always recognised yet.

Does VoiceOver read the result?

Yes. The PDF contains real text with headings, paragraphs, tables and image descriptions. You add image descriptions in the report.

Are my worksheets uploaded to the internet?

No. Everything is processed on the device. See Privacy.
