Guide

An easy-to-read worksheet in three steps.

1. Open a worksheet

  • Open PDF: choose a file from Files or drag it onto the drop area.
  • Scan printed pages (iPad): place the sheet, the camera detects the edges. Capture several pages one after another.
  • Photos (JPEG, PNG, HEIC): open or drag them in. Each photo becomes a page.
  • Mac: File menu → Import from iPhone → Scan Documents.

If a PDF contains scanned pages without real text, the app asks whether text recognition should read them. This takes about one second per page.

2. Adjust

Layout

  • Reflow: text and images flow onto new A4 pages. The document gets longer but is calmest to read.
  • Keep layout: text stays in its place. If there is not enough space for your settings, that page is reflowed automatically.

Font and spacing

  • Typeface Verdana, Arial or unchanged; size as original, 14, 16 or 18 points.
  • Line spacing as original, 1.5× or 2×.
  • Space between letters off, slight or strong. VoiceOver still reads whole words.

Images and colours

  • Images on their own line: every image stands alone, the text continues below.
  • Sharpen images: more contrast and sharpness for photos.
  • Colours: black on white, yellow on black or black on cream.

Profiles

Save the settings for a child under a name (“Save as profile …”) and choose them again later with one tap. Profiles stay on this device.

3. Check and save

  • The preview shows original and result side by side – the result is exactly the PDF that will be saved.
  • The report shows what to check (e.g. pages read by text recognition). There you can also add image descriptions for VoiceOver.
  • Save puts Name_CVI.pdf into Files.

Keyboard

⌘O open · ⌘S save · ⌘I report · ⌘← / ⌘→ turn pages
