Die App

  • Keine Datenerhebung: Die App erhebt, speichert oder übermittelt keine Personendaten. Es gibt keine Anmeldung, keine Werbung, keine Analyse- oder Tracking-Werkzeuge und keine Verbindung zu eigenen Servern.
  • Dateien: Die App liest nur Dateien, die Sie selbst auswählen. Das Ergebnis wird dort gespeichert, wo Sie es ablegen.
  • Kamera: Die Kamera wird nur verwendet, wenn Sie «Gedruckte Seiten scannen» wählen. Die Aufnahmen werden auf dem Gerät verarbeitet und nicht gesendet.
  • Texterkennung: Die Texterkennung läuft vollständig auf dem Gerät (Apple Vision). Es werden keine Inhalte an Dritte übermittelt.
  • Einstellungen und Profile: Werden nur lokal auf dem Gerät gespeichert. Profile können einen Vornamen enthalten; sie verlassen das Gerät nicht. Sie löschen sie in der App («Profil löschen») oder indem Sie die App entfernen.
  • Kauf: Käufe laufen über den App Store von Apple. Apple verarbeitet dabei Ihre Zahlungsdaten nach der Datenschutzerklärung von Apple. Ich erhalte keine Personendaten, nur zusammengefasste Verkaufszahlen.

Diese Webseite

Die Webseite verwendet keine Cookies, keine Analyse-Werkzeuge und keine Schriften oder Inhalte von fremden Servern. Sie wird über GitHub Pages bereitgestellt (GitHub, Inc., USA). GitHub kann aus technischen und Sicherheitsgründen Zugriffsdaten wie die IP-Adresse speichern; dabei können Daten in die USA übermittelt werden. Details: Datenschutzerklärung von GitHub.
